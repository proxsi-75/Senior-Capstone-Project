## Project Overview
This project is a lightweight weather dashboard system developed in Python.
The system can obtain real-time geographic coordinates and 7-day weather forecast data through public APIs,
store data locally, generate visual temperature charts, and display weather forecast information.

The whole project will be completed in 8 sessions with iterative development,
including system design, module coding, testing, optimization and final demonstration.

## Technology Stack
- Programming Language: Python 3.10+
- Core Libraries: requests, matplotlib
- External API: Open-Meteo Weather API, OpenStreetMap Geocoding API
- Development Tool: VS Code
- Version Control: Git & GitHub
